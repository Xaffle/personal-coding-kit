# personal-coding-kit

本仓库收集可复用的 AI 智能体技能，技能文件位于 `skills/` 目录。每个技能目录包含入口文件 `SKILL.md`，以及完成任务所需的参考资料。

## 技能列表

| 技能 | 用途 |
| --- | --- |
| [experiment-report](skills/experiment-report/SKILL.md) | 设计、撰写、审核和修订实证实验方案及报告，涵盖实验方法、结果与局限。 |
| [html-slide-deck-generator](skills/html-slide-deck-generator/SKILL.md) | 分阶段规划并生成 HTML 演示文稿。 |
| [tech_blog_specialist](skills/tech_blog_specialist/SKILL.md) | 为技术读者撰写或编辑 AI 趋势、洞察与技术分析博客。 |
| [write-cn-tech](skills/write-cn-tech/SKILL.md) | 撰写、改写和审核中文技术文档，关注论证、概念解释与读者需求。 |

## 使用

按所用智能体工具的技能加载方式，将所需技能的完整目录提供给工具，包括 `SKILL.md` 和目录内的参考文件。也可以打开对应的 `SKILL.md`，查看技能的适用范围和工作流程。
