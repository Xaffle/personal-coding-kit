# 实验方案与报告参考大纲

根据研究问题、实验阶段、读者和交付要求选择章节。用户提供的大纲优先；无需为凑齐模板保留不适用的标题。

## 通用结构

1. **基本信息与摘要**：主题、日期、版本、研究问题；已有结果时概述主要发现和结论。
2. **背景与目标**：问题背景、现有依据、研究目标和适用的假设。
3. **实验设计**：实验对象与单位、选择条件、变量、实验条件或比较对象、样本量依据及设计限制。
4. **材料与方法**：材料、设备或数据来源，操作流程，测量方式，以及足以理解和复核实验的条件。
5. **评价与分析方法**：指标定义、分析单位、分母、排除规则、重复方式及适用的统计或其他分析方法。
6. **结果**：按研究问题呈现观察和分析结果，交代样本量、缺失、失败及不确定性；图表注明单位和数据来源。
7. **讨论与局限**：解释结果与假设的关系，讨论替代解释、偏差、混杂因素和适用范围。
8. **结论**：回答研究问题，说明证据支持的结论和仍待验证的问题。
9. **附录**：按需提供详细配置、原始记录索引、计算过程、补充结果或复现材料。

实验方案通常使用第 1 至 5 项，并写明记录和分析计划。未执行的步骤用计划时态，预期观察与实际结果分开。进行中的研究应区分已完成部分和后续计划。

## 按需选用的内容

- 算法与数据：数据来源和版本、划分单位、预处理、基线、模型配置、随机种子、计算资源、适用的消融或稳健性分析。
- 硬件与实验室：仪器及规格、校准、材料批次、环境条件、测量不确定度、操作步骤和质量控制。
- 用户研究：参与者招募与筛选、任务和情境、观察或访谈方法、记录方式、分析单位以及适用的隐私、同意和伦理要求。
- 工程验证：测试环境、覆盖范围、验收标准和失败情况；当它与研究实验并存时，分别说明各自回答的问题及结果。

具体内容取决于实验设计。未做的实验或不可获得的记录应如实说明，不得用推测补齐。
